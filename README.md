# Khang — Bản đồ xây dựng Agent

Website cá nhân tĩnh. Để xuất bản bằng GitHub Pages:

1. Mở **Settings → Pages** trong repository.
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn branch **main**, thư mục **/(root)**, rồi nhấn **Save**.
4. Chờ GitHub tạo trang tại `https://khang2501nguyen-coder.github.io/Khang/`.

Repository này đang công khai để mọi người truy cập website. Tiến độ checklist được lưu riêng trên trình duyệt của từng người xem.
